## Results

```bash

  --with numpy --with scipy --with pytest --with matplotlib --with pyyaml --with mpi4py \
  -- python -m pytest
```

Result: **252 passed, 1 skipped**. The one skip is the DOLFINx-backed FEM fixture. The
cluster module catalog contains no FEniCS/DOLFINx installation, and the repository does
not include the large FEM meshes needed for the A2 cylinder campaign.

The synthesis and new validation tier also passed against the older numerical stack
NumPy 1.26.4 and SciPy 1.12.0. This checks that the feature implementation and tolerant
regression gate work on both NumPy 1.x and 2.x.

## Cylinder result

All three analytical cases passed. For each case, the independently assembled Farina
waveform and analytical reciprocal field sent through `field_to_muap` had the same time
axis, signed correlation at least `1 - 1e-13`, and peak ratio within `2e-12` of one. The
relative error in the reciprocal `C(kz) -> phi(z) -> C(kz)` round trip was below `1e-13`.

This result validates the analytical field-to-MUAP operator, including normalization,
sign, physical time and the millivolt-to-volt adapter boundary. It does not substitute
for the planned like-for-like FEM-cylinder mesh and domain convergence experiment.
